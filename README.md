# AG音频解析 Chrome 扩展

![Version](https://img.shields.io/badge/version-2.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

一个优雅的音频播放检测和下载工具 Chrome 扩展，支持音频试听、下载、批量打包下载、悬浮图标开关、错误处理优化、标签页状态同步。当前主要针对爱给网场景进行测试。

## ✨ 特性

### 🎯 智能检测（双通道）
- 播放触发检测：当页面中的 `audio` 元素实际播放时上报资源
- 网络请求检测：监听请求 URL 与响应头中的音频特征
- 支持常见音频格式识别：MP3 / WAV / OGG / M4A / AAC / FLAC（以及部分响应头可识别格式）
- 多策略去重，尽量减少重复和误报

### 🎵 音频试听
- 弹窗内试听/停止
- 实时进度条显示
- 支持进度条点击定位与拖动
- 播放状态同步

### 💾 下载功能
- 单个音频下载
- 批量打包下载（ZIP）
- 文件名清洗与智能命名
- 下载状态反馈

### 🎨 界面设计
- 现代化 iOS 风格界面
- 响应式布局
- 流畅动画与空状态提示

### 🛠 其他功能
- 悬浮图标开关（可在弹窗中控制）
- 标签页资源状态同步
- 针对异常场景的错误处理与降级

## 🚀 技术栈

- Chrome Extension API (Manifest V3)
- JavaScript (ES6+)
- HTML5 Audio API
- JSZip
- CSS3

## 📦 安装

1. 下载源代码
2. 打开 Chrome 扩展页面（`chrome://extensions/`）
3. 开启“开发者模式”
4. 点击“加载已解压的扩展程序”
5. 选择项目目录

## 🔧 使用方法

1. 打开含有音频的网页
2. 触发页面音频播放（建议）
3. 点击扩展图标查看检测到的音频
4. 可在弹窗内试听、单个下载或“下载全部”

## ⚠️ 说明与限制

- 本扩展采用“播放事件 + 网络请求”双通道检测，不保证所有站点都能完整识别。
- 对防盗链、鉴权签名、分片流媒体（如部分 HLS/MSE）等资源，可能存在无法直接下载的情况。
- “跨域资源访问”能力受目标站点策略影响，扩展会尽力兼容但无法 100% 保证。
