# Chrome 应用商店素材

本目录存放提交 Chrome 应用商店所需的图形素材与文案，不随扩展打包发布。

## 图标

图标位于项目的 `icons/` 目录，已在 `manifest.json` 中声明：

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| `icons/icon16.png` | 16×16 | 页签图标、右键菜单 |
| `icons/icon32.png` | 32×32 | Windows 系统显示 |
| `icons/icon48.png` | 48×48 | 扩展管理页 |
| `icons/icon128.png` | 128×128 | 安装流程与商店详情页 |
| `icons/store-icon128.png` | 128×128 | 商店列表页，白色不透明底 |

图标依据原 logo 重绘，按尺寸分别调整描边粗细与波形条数量：16px 版本省略播放三角并减至 3 条波形，避免小尺寸下糊成一团。前四个文件为透明底，`store-icon128.png` 为白色底，供商店后台「商店图标」一栏使用。

## 商店文案

**名称**

```
AG 音频解析 - 网页音频嗅探与下载
```

**简短说明**（上限 132 字符）

```
自动嗅探网页音频资源，支持在线试听、单个下载与批量 ZIP 打包，覆盖 MP3/WAV/OGG/M4A/AAC/FLAC 等主流格式。
```

**详细说明**

```
AG 音频解析是一款基于 Chrome Manifest V3 的网页音频工具，帮助你在浏览网页时快速定位并保存页面中的音频资源，无需借助开发者工具或第三方抓包软件。

【自动嗅探】
采用网络请求监听与页面元素监听双通道检测。前者拦截请求与响应头，依据 MIME 类型识别音频流；后者捕获页面中 audio 元素的播放事件并提取标题。两条通道互为补充，覆盖静态链接与动态加载两类场景。

支持 MP3、WAV、OGG、M4A、AAC、FLAC、WebM 等主流格式。

【在线试听】
在扩展面板内直接试听，无需跳转或下载。进度条支持拖拽定位，实时显示播放时间与总时长。试听优先复用页面已有的媒体元素，避免重复请求。

【下载管理】
支持单文件下载与多文件 ZIP 打包。批量任务采用串行获取策略，逐个下载并实时反馈进度，避免大文件并发导致的内存峰值。

文件命名依据响应头的 MIME 类型判定真实格式，并按标题、URL 路径、时间戳的优先级生成名称，自动过滤文件系统非法字符。

【会话隔离】
音频记录按标签页独立存储，页面跳转时自动清空，标签页关闭时释放资源，多标签并行工作时互不干扰。

【关于权限】
扩展需要访问所有网站的权限，用于在你浏览的页面中检测音频资源。所有处理均在本地完成，不收集、不上传任何用户数据。

【开源】
项目已在 GitHub 开源，欢迎反馈问题与提交改进：
https://github.com/Achordchan/music-chrome

【使用提醒】
本扩展仅供学习研究与个人合法用途。请遵守目标网站的服务条款及所在地区的法律法规，尊重内容创作者的版权。
```

**类别**：工具

**语言**：中文（简体）

## 提交前须知

商店要求填写隐私权做法与权限用途说明。本扩展声明的权限对应用途如下：

| 权限 | 用途说明 |
| --- | --- |
| `activeTab` | 读取当前标签页中的音频元素信息 |
| `webRequest` | 监听网络请求以识别音频资源地址 |
| `downloads` | 保存音频文件到本地 |
| `storage` | 保存悬浮入口显示与否的用户偏好 |
| `tabs` | 按标签页隔离音频记录 |
| `declarativeNetRequestWithHostAccess` | 改写特定站点的请求头以完成跨域获取 |
| `host_permissions: <all_urls>` | 音频资源可能来自任意域名，需在用户浏览的页面中检测 |

数据用途一栏需声明「不收集用户数据」——扩展所有处理均在本地完成，无远程上报。

首次提交需支付一次性开发者注册费，审核通常需要数个工作日。
